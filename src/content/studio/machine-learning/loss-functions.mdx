<Chapter id="intuition" title="A number for being wrong" objective="Separate the prediction from the score you give it.">

A model emits a number. A loss turns that number, and the answer you wanted, into a single measure of disagreement.

This figure has no model. You are the model: the prediction slider is the output, and the target is the answer. The curve is every prediction from 0 to 1, scored against the target you chose. The marker is the prediction you are on now.

Two scores are here, because they punish a miss differently. Squared error cares about the size of the gap. Cross-entropy cares about how much probability you assigned to the label that was true.

</Chapter>

<Chapter id="mse" title="Squared error" objective="Read the parabola.">

For a prediction <Equation tex="\hat{y}" display={false} /> and a target <Equation tex="t" display={false} />,

<Equation tex="(\hat{y} - t)^2." />

The default is prediction 0.20 and target 1. The gap is 0.80 and the loss is 0.64. Move the prediction onto the target and the loss is 0. Move it the same distance to the other side and the loss is the same, because the gap is squared. The curve is a parabola and its bottom is the target. Drag the target and the bottom moves with it.

Both sliders run from 0 to 1 so this curve can sit next to the cross-entropy curve. A squared error in a real regression is not limited to that interval. The shape is the same.

</Chapter>

<Chapter id="bce" title="Cross-entropy" objective="Read a loss that is not symmetric around the label.">

The label <Equation tex="t" display={false} /> is 0 or 1. The prediction <Equation tex="\hat{y}" display={false} /> is read as a probability. The loss is

<Equation tex="-\left(t \log \hat{y} + (1 - t) \log (1 - \hat{y})\right)." />

If the label is 1, this is <Equation tex="-\log \hat{y}" display={false} />. Predicting 1 would be a loss of 0. Predicting something small is a large loss, and the loss grows without a bound as the prediction approaches 0. The label-0 case is the mirror: <Equation tex="-\log (1 - \hat{y})" display={false} />.

The logarithm is undefined at 0 and at 1. The figure clamps the prediction to the open interval from <Equation tex="10^{-4}" display={false} /> to <Equation tex="1 - 10^{-4}" display={false} /> before taking the log. The slider itself starts at 0, so the marker can sit on the edge while the number in the caption uses the clamp.

Switch the label and do not touch the prediction. The same output is a different loss, because the loss asks how much probability you gave the label that occurred, not how close you were to a number on a line.

</Chapter>

<Chapter id="continue" title="What to open next" objective="Take the number into a search that tries to shrink it.">

[Gradient descent](/studio/gradient-descent) is a walk that tries to make a loss smaller. The surface there is a designed function of two parameters. It is this kind of number, drawn so the walk is visible. The step does not know the formula. It only uses the slope where it stands.

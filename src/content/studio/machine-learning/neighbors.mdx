<Chapter id="intuition" title="Ask the nearest examples" objective="Say what the lines are for.">

There is no equation being fitted. The labeled points are the whole model. A new point is given the label that wins a vote among the points closest to it.

Ink points are class 0. Accent points are class 1. The ring is the query. The lines are the neighbours allowed to vote. Change k and the set of lines changes. The points do not.

</Chapter>

<Chapter id="distance" title="Distance, then a count" objective="See why k = 5 disagrees with k = 3 at the origin.">

The distance from the query <Equation tex="(x, y)" display={false} /> to a point <Equation tex="(x_i, y_i)" display={false} /> is

<Equation tex="\sqrt{(x - x_i)^2 + (y - y_i)^2}." />

The k smallest distances vote. If two distances are equal, the point earlier in the fixed list is kept. If the vote splits evenly, the caption says the classes tie. It does not pick one.

At the origin the three nearest are class 0, class 1, and class 0, in that order. k = 1 sees only the first, class 0. k = 3 sees two of class 0 and one of class 1. k = 5 takes two more class-1 points, and the vote becomes class 1. Same points, same query, different k.

</Chapter>

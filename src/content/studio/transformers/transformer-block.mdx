<Chapter id="tokens" title="Two tokens, three coordinates" objective="Keep the block inside the numbers on the page.">

Token A starts at <Equation tex="(1, 0, 0)" display={false} />. Token B starts at <Equation tex="(0, 1, 0)" display={false} />. There is no sentence and no trained matrix. The attention weights are fixed: A puts 0.75 on itself and 0.25 on B. B puts 0.25 on A and 0.75 on itself.

The mix is a weighted average of those two vectors. For A it is <Equation tex="(0.75, 0.25, 0)" display={false} />. For B it is <Equation tex="(0.25, 0.75, 0)" display={false} />.

</Chapter>

<Chapter id="residual" title="The add is the block" objective="See the mix land on top of the input, not instead of it.">

The next stop adds the input back. A becomes <Equation tex="(1, 0, 0) + (0.75, 0.25, 0) = (1.75, 0.25, 0)" display={false} />. B becomes <Equation tex="(0.25, 1.75, 0)" display={false} />.

That add is the residual. The block does not replace the token with the mix. It keeps the token and writes the mix beside it. If the mix were zero, the token would leave this stop unchanged.

</Chapter>

<Chapter id="forward" title="The feed-forward has a threshold" objective="Say why one token grows a third coordinate and the other does not.">

The feed-forward on this page is one rule. If the first coordinate is above 1, write the excess into the third coordinate. Otherwise write nothing.

A’s first coordinate is 1.75, so the excess is 0.75. The feed-forward vector is <Equation tex="(0, 0, 0.75)" display={false} />, and the last add makes <Equation tex="(1.75, 0.25, 0.75)" display={false} />.

B’s first coordinate is 0.25. The excess is 0. The feed-forward vector is <Equation tex="(0, 0, 0)" display={false} />, and the last add changes nothing: <Equation tex="(0.25, 1.75, 0)" display={false} />.

A real feed-forward is a learned matrix, a bend, and another matrix. This one is a threshold you can check with a subtraction. The shape of the block is the same shape: mix, add, transform, add.

</Chapter>

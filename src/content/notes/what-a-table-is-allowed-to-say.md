A table is a list of measurements. Each row is a system, or a setup. Each column is a metric on a named set. The table can support the sentence "on this set, under this metric, these were the scores." It supports a sentence about cause only when the rows differ in the cause and match in everything else that could have moved the score. If they also differ in size, data, or budget, the table does not isolate the cause. The caption does not get to isolate it anyway.

[A baseline is the comparison](/knowledge/a-baseline-is-the-comparison) is the minimum: some other row to subtract. [The setup is part of the result](/knowledge/the-setup-is-part-of-the-result) is the rest of the row, the part that often lives in an appendix or not at all. A reader who quotes the bold number and not the unmatched column has made a claim the table refused.

## Means, spreads, and single runs

If a cell is a mean over runs, the spread belongs next to it, or the mean pretends the run did not move. If a cell is one run, it should look like one run. [A held-out set is still a sample](/knowledge/a-held-out-set-is-still-a-sample) applies to the rows inside the metric as well as to the runs. A table that sorts systems by a gap smaller than the noise is a sorting of noise.

## What this does not say

A cautious reading is not a refusal to decide. You can prefer the top row for a practical reason — it is the system you can run, the score is on the task you have — while refusing the causal sentence. Use the table for the decision it can actually feed.
